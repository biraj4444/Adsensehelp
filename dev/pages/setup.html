The steps

  1. 1

    Create your AdSense account

    Account
    • WhatThe account that owns your ad code and payments.
    • DoGo to the AdSense website, sign in with a Google Account and follow the sign-up questions.
    • VerifyYou can see your publisher ID (pub- and 16 digits) in your account.
    [[official]]

    Applicants must be at least 18. Under-18 applicants can have a parent or guardian sign up with their own Google Account, and payments go to that adult.

    [[/official]] [[tip]]

    Use a Google Account you will keep for years and turn on two-step verification. If you lose it you lose the ad account.

    [[/tip]]
    [[media setup-account | Example: sign-up screen | Add a screenshot or video URL]]
  2. 2

    Add your site

    Site
    • WhatTell AdSense which website you want to use.
    • DoEnter the address exactly as visitors reach it, including https:// and either www or no www.
    • MistakeEntering example.com while your site redirects to www.example.com, or the reverse.
    [[tip]]

    Pick one address as the main one and redirect the other to it permanently. Then use only that address everywhere.

    [[/tip]]
    [[media setup-add-site | Example: adding a site | Add a screenshot or video URL]]
  3. 3

    Choose how to connect it

    Connect
    • WhatYou prove to AdSense that the site is yours.
    • DoAdSense shows one or more methods, depending on your account and site. These can include a code snippet, an ads.txt snippet or a meta tag. Use the method it shows you.
    • RuleCopy the exact text AdSense gives you. Do not retype it.
    [[official]]

    You need to be able to place AdSense code between the head tags of your pages. See Access to your site's HTML.

    [[/official]]
    [[media setup-connect | Example: connection methods | Add a screenshot or video URL]]
  4. 4

    Add the code to your page head

    Code
    • WhatOne script that loads Google's ad library.
    • WhereInside <head>, once per page, on every page that should show ads. Put it in your shared layout.
    • VerifyView Source on the live page and search for adsbygoogle.
    [[code html index.html hl=2-5]] [[/code]] [[official]]

    AdSense code is placed between the head tags of your pages.

    [[/official]]

    Using React, Next.js, Flask, Django, PHP or WordPress? Open the Code Lab for the exact file and placement. Enter your ID there and this box fills in too.

    [[media setup-code | Example: code in the head | Add a screenshot or video URL]]
  5. 5

    Verify the code is really live

    Verify
    • WhatConfirm that the code is in the HTML your server sends, then press the verify button in AdSense.
    • DoOpen your live page, choose View Source (not Inspect), search for adsbygoogle.js. Paste the source into the HTML checker.
    • WhyInspect shows code added by JavaScript after load. Verification needs it in the page HTML.
    [[tip]]

    Deploy first, verify second. A cached or old build is the most common reason verification fails.

    [[/tip]]
    [[media setup-verify | Example: View Source | Add a screenshot or video URL]]
  6. 6

    Publish your ads.txt file

    ads.txt
    • WhatA public text file listing who may sell ads on your site.
    • WhereThe root of your domain, so it opens at https://yourdomain.com/ads.txt.
    • VerifyOpen that address in a browser. It must show plain text.
    [[code text ads.txt]] google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0 [[/code]] [[official]]

    ads.txt is not mandatory but is highly recommended. If the file displays in your browser, AdSense is likely to find it. Changes can take time to appear. See the Ads.txt guide.

    [[/official]]

    Build and validate yours with the ads.txt tools.

    [[media setup-adstxt | Example: ads.txt in a browser | Add a screenshot or video URL]]
  7. 7

    Wait for review (and keep calm)

    Review
    • WhatGoogle reviews the site. The decision and the timing are Google's.
    • DoLeave the code in place, keep the site online and check your account and email for messages.
    • Don'tMake big changes to the site mid-review, or pay anyone who promises approval.
    [[warn]]

    No tool, service or guide, including this one, can guarantee approval. If something is flagged, the message in your account says what to fix.

    [[/warn]]
    [[media setup-review | Example: account status | Add a screenshot or video URL]]
  8. 8

    Create ads: Auto ads or ad units

    Ads
    • Auto adsTurn them on for the site in AdSense. Google chooses positions. Needs only the head script.
    • Ad unitsCreate a unit in AdSense, then paste its markup where the ad should appear. One push call per unit.
    • TipStart with one or two responsive units in clear spots.
    [[code html article.html hl=1-8]] [[/code]] [[official]]

    Do not encourage clicks or point attention at ads with arrows or graphics, and do not place ads in pop-ups, emails or on pages without content.

    [[/official]]

    Generate this for your own slot and format with the ad unit builder.

    [[media setup-units | Example: creating an ad unit | Add a screenshot or video URL]]
  9. 9

    Go live: free static hosting

    Launch
    • WhatPut your site on the internet with HTTPS and your own domain.
    • HostsGitHub Pages, Cloudflare Pages or Netlify can serve a static site for free. Check each one's current limits.
    • RememberPut ads.txt and robots.txt in the published folder so they sit at the root.
    [[code bash Termux hl=5-6]] pkg install git python cd my-site git init && git add . && git commit -m "First version" git branch -M main git remote add origin https://github.com/YOUR-USER/YOUR-REPO.git git push -u origin main [[/code]]

    Then connect the repository in your host's dashboard, add your custom domain, and follow the DNS records it shows. Wait for the HTTPS certificate before verifying in AdSense.

    [[tip]]

    Preview locally first: python -m http.server 8080 in your site folder, then open http://localhost:8080.

    [[/tip]]

Hosting changes, redesigns and theme updates can quietly remove your code. A short routine catches that early.
